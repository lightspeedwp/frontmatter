Create a complete `.github/instructions/contribution-guidelines.md` file that documents how to contribute to the LightSpeed project. The file should:

## Frontmatter Requirements

1. Have complete LightSpeed instruction file frontmatter with:
   - `file_type: instruction`
   - Clear title and description
   - Version tracking
   - Created and last updated dates (ISO 8601 format: YYYY-MM-DD)
   - Author and owner information
   - Appropriate status and stability
   - Relevant tags (max 8)
   - Domain set to "governance"
   - Mode set to "instruction"

## Content Requirements

Include realistic contribution guidelines content covering:
- Code style standards and conventions
- Pull request process and requirements
- Testing requirements and test coverage expectations
- Documentation standards for code changes
- Branch naming conventions aligned with LightSpeed strategy
- Commit message format requirements
- Review process and expectations
- Common contributing gotchas and how to avoid them

## Technical Requirements

Ensure frontmatter:
- Uses ISO 8601 dates (YYYY-MM-DD)
- Has proper YAML formatting
- Follows LightSpeed naming conventions
- Includes all recommended fields
- Is ready for lefthook validation

## Output

A complete `.github/instructions/contribution-guidelines.md` file with:
1. Valid LightSpeed instruction frontmatter
2. File size ~300-400 lines total
3. Proper YAML structure
4. Ready to pass validation scripts
5. Includes realistic, production-ready contribution guidelines content
